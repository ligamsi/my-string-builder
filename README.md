# MyStringBuilder

Простая реализация изменяемой строки на Java с поддержкой отмены последних изменений с использованием паттерна **Snapshot (Memento)**.

## Возможности

- Добавление строк с помощью `append()`.
- Удаление части строки с помощью `delete()`.
- Отмена последнего изменения с помощью `undo()`.
- Цепочка вызовов методов (Method Chaining).
- Получение текущего содержимого строки с помощью `toString()`.

## Используемые технологии

- **Java 21**
- **Maven** - управление сборкой проекта и зависимостями.
- **JUnit 5** - написание и запуск автоматических тестов.

## Запуск тестов

Для запуска автоматических тестов выполни команду в терминале из корневой директории проекта:

```bash
mvn clean test
```

Тесты проверяют добавление строк, удаление подстрок, отмену добавления и восстановление состояния после удаления.

## Цель проекта

Проект создан для практики Java Core и демонстрирует применение следующих концепций:

- работа с изменяемыми строками;
- использование коллекции `Deque` для хранения истории изменений;
- реализация паттерна Snapshot (Memento);
- написание автоматических тестов с использованием JUnit 5;
- сборка проекта с помощью Maven.
